Project Summary: End-to-End Kubernetes DevSecOps Tetris Game**

I successfully designed and implemented a complete DevSecOps pipeline for deploying a React-based Tetris game on Kubernetes. This project demonstrates modern cloud-native development practices with robust security integration.

Key Achievements:
- Built automated CI/CD pipeline using Jenkins for seamless application deployment
- Implemented comprehensive security scanning with SonarQube, OWASP Dependency-Check, and Trivy
- Containerized the Tetris application using Docker and deployed to Kubernetes
- Utilized ArgoCD for GitOps-based continuous deployment
- Configured AWS Load Balancer for public accessibility
- Established full-stack monitoring and quality gates

 Tools Explored 🛠️
1. Jenkins:Automated CI/CD pipelines
2. ArgoCD: Continuous deployment to Kubernetes
3. Kubernetes: Orchestration for containerized applications
4. Trivy: Container vulnerability scanner
5. OWASP Dependency-Check:** Ensuring secure dependencies
6. Docker: Containerized application deployment
7. SonarQube: Unveiling code quality insights
8. Terraform: Infrastructure as Code for AWS EKS
